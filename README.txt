ผู้พิทักษ์จิ๋ว - AR เกมป้องกันสิ่งเสพติด (ฉบับแก้ไข)

แก้ไขหลัก:
1. เปลี่ยน MediaPipe Tasks Vision เป็น 0.10.35 ซึ่งยังใช้งาน vision_bundle.mjs ได้
2. เปลี่ยนการ import เป็น dynamic import เพื่อให้ปุ่มเริ่มเกมยังทำงานและแสดงข้อผิดพลาดได้ หาก CDN โหลดไม่ได้
3. ไม่ซ่อนหน้าเริ่มเกมก่อนตรวจสอบกล้องสำเร็จ
4. เพิ่มข้อความแจ้งเตือนกรณีเปิดไฟล์แบบ file:// ซึ่งเบราว์เซอร์จะไม่อนุญาตกล้อง
5. เพิ่มโหมดสำรอง: แตะ/ลากหน้าจอเพื่อควบคุมโล่ได้ แม้ระบบตรวจใบหน้าโหลดไม่ได้
6. เก็บไฟล์รูปทั้งหมดไว้เหมือนเดิม

วิธีเปิดที่แนะนำ (สำคัญสำหรับกล้อง)

วิธี A: Python
- แตก ZIP
- เปิด Terminal/Command Prompt ในโฟลเดอร์ที่มี index.html
- รัน: python -m http.server 8000
- เปิด: http://localhost:8000

วิธี B: VS Code
- เปิดโฟลเดอร์นี้ใน VS Code
- ใช้ Live Server
- เปิดหน้าเว็บจาก localhost

บน iPhone/iPad: หากจะใช้กล้องจากอุปกรณ์จริง ควรเผยแพร่ผ่าน HTTPS หรือใช้โฮสต์ที่เป็น HTTPS; การเปิดไฟล์ HTML ตรง ๆ จาก Files/file:// อาจไม่อนุญาตกล้อง
